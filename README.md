# 🌼 AI랑 놀아봐요!

어르신을 위한 **모바일 우선 AI 프롬프트 체험 웹사이트**의 첫 버전이야.
HTML / CSS / 순수 JavaScript만 사용하며 외부 라이브러리, 로그인, 서버, API 키가 필요 없어.

## 기능

- 카테고리별 질문 카드 6종 (노래, 요리, 운동, 문자, 나들이, 그림)
- 선택값에 따라 질문 자동 완성
- 질문 복사, ChatGPT 새 창 열기, 추가 질문 복사
- AI 환각(할루시네이션), 딥페이크, 개인정보 주의사항
- 모바일 대응, 큰 버튼 및 큰 글씨, 키보드 접근성 고려

## 파일 구조

```text
ai-playground/
├── index.html
├── .nojekyll
├── css/
│   └── style.css
└── js/
    ├── prompts.js    # 내용 추가·수정: 카테고리/질문/선택지
    └── app.js        # 질문 카드 화면 및 복사 동작
```

## 실행

`index.html` 파일을 브라우저로 열어도 화면을 확인할 수 있어.
복사 기능은 브라우저 권한에 따라 로컬 파일에서 작동하지 않을 수 있으니 **배포된 HTTPS 주소에서 스마트폰으로 반드시 테스트**해줘.

## GitHub Pages 배포

1. GitHub에서 새 저장소(예: `ai-playground`)를 생성해.
2. 이 폴더 **안의 모든 파일**을 저장소 최상위에 올려. (`index.html`이 저장소 루트에 있어야 해.)
3. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch**를 선택해.
4. **Branch: `main` / Folder: `/(root)`**로 설정하고 **Save**를 눌러.
5. 배포 주소가 표시되면 접속해 확인해. 일반적인 프로젝트 사이트 주소 형식은 `https://계정이름.github.io/ai-playground/`야.
6. 배포된 **정확한 URL**로 QR코드를 만들고, 실제 스마트폰에서 열어보면 돼.

GitHub Pages 사이트는 누구나 방문할 수 있는 **공개 웹페이지**야. 사용자 개인정보나 비밀정보, API 키를 올리지 마.

## 질문 추가하기

`js/prompts.js`의 `PROMPT_CARDS` 배열에 새 항목을 추가해.

```js
{
  id: 'books', category: 'life', icon: '📚',
  title: '읽을 책 추천받기',
  description: '좋아하는 주제를 선택해요.',
  template: '{topic}에 관한 입문용 책을 {count}권 추천해줘.',
  fields: [
    { key: 'topic', label: '어떤 주제?', options: ['역사', '여행', '소설'] },
    { key: 'count', label: '몇 권?', options: ['3', '5'] }
  ],
  caution: '도서 정보가 실제와 다를 수 있으니 확인하세요.'
}
```

`fields.key`와 `template`의 `{key}` 문자열은 반드시 같아야 해.

## 테스트 체크리스트

- [ ] 스마트폰에서 QR로 접속 시 글씨가 읽기 쉬운가?
- [ ] 버튼과 선택칸을 손가락으로 누르기 쉬운가?
- [ ] 선택 항목에 따라 완성된 질문이 바뀌는가?
- [ ] 복사 성공 메시지가 표시되는가?
- [ ] ChatGPT에 붙여넣기가 되는가? (로그인 필요할 수 있음)
- [ ] AI가 만든 정보·이미지에 관한 주의사항이 잘 보이는가?

## 참고

- 'ChatGPT 열기'는 ChatGPT 웹페이지를 여는 링크야. 다른 사이트 입력창에 **자동으로 질문을 붙여넣거나 전송하지는 않아.**
- 복사는 HTTPS 주소에서 가장 안정적으로 동작해. 구형 브라우저를 위한 대체 복사 방식도 넣었어.
- 이 사이트는 AI에 직접 연결하지 않고, 질문 문장만 생성해. 사용자 입력값도 서버에 전송하지 않아.

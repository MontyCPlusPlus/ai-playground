# 🛠️ 프롬프트 데이터 수정 가이드 (`js/prompts.js`)

이 문서는 AI Playground 웹사이트에 새로운 프롬프트를 추가하거나 기존 내용을 수정하는 방법을 안내합니다. 

이 프로젝트는 별도의 데이터베이스(DB) 없이 순수 웹 브라우저 환경에서 동작하므로, `js/prompts.js` 파일 내부의 데이터만 수정하면 웹페이지에 즉시 반영됩니다.

GitHub Pages를 통해 페이지를 호스팅한 경우(저장소를 포크한 이후 웹페이지 링크를 만든 경우), GitHub 페이지에서 직접 파일을 수정하거나 `git push` 명령어를 통해 저장소 내의 파일을 업데이트해야 합니다.
이것에 대한 자세한 사항은 이 문서의 3번 문단을 확인하십시오.

## 1. `prompts.js` 데이터 구조

`prompts.js`의 데이터는 자바스크립트 객체 배열(Array of Objects) 형태로 저장되어 있습니다.

파일을 열어보시면 아래와 같은 3가지의 구조를 확인할 수 있습니다.

```javascript
// 1. 카테고리 목록
window.PROMPT_CATEGORIES = [
    { id: 'all', label: '전체 보기', icon: '✨' },
    { id: 'music', label: '음악', icon: '🎵' },
    // ...
]

// 2. 프롬프트 카드 목록
window.PROMPT_CARDS = [
    {
        id: 'songs', category: 'music', icon: '🎵', title: '좋아하는 가수의 대표곡 찾기',
        description: '가수 이름과 곡 수를 골라보세요.',
        template: '가수 {artist}의 대표곡 {count}곡을 알려줘.',
        fields: [
        { key: 'artist', label: '어떤 가수를 찾아볼까요?', options: ['남진', '태진아', '송대관', '나훈아', '이미자', '주현미'] },
        { key: 'count', label: '몇 곡을 알려드릴까요?', options: ['5', '10', '15'] }
        ],
        caution: 'AI는 가수·노래 제목을 틀릴 수 있어요. 음악 서비스 등에서 다시 확인해요.'
    },
    // ...
]

// 3. 후속 질문 목록
window.FOLLOWUP_PROMPTS = [
  '더 쉽게 설명해줘.',
  '조금 더 짧게 정리해줘.',
  // ...
];
```

## 2. 각 데이터의 역할 및 수정 방법

코드를 수정하는 목적에 맞게 3가지 구역 중 하나에 데이터를 추가하거나 기존 데이터를 수정합니다.

항목을 추가하기 위해서는 각 대괄호 블럭([]) 안에 새로운 중괄호 블럭({})을 추가한 후, 중괄호 블럭 안을 아래에서 설명하는 방식과 동일하게 채웁니다.

**각 중괄호 블럭은 반드시 쉼표(,)로 구분되어야 합니다.** 마지막 블럭 뒤의 경우에는 쉼표를 추가할 필요가 없습니다.

### 2.1. 카테고리 추가하기 (window.PROMPT_CATEGORIES)

화면 상단의 메뉴 탭에 표시되는 카테고리(주제)를 관리합니다.

* `id`: 카테고리의 고유 영문 이름 (예: health, travel)

* `label`: 화면에 표시될 한글 이름 (예: 건강, 여행)

* `icon`: 카테고리를 꾸며줄 이모지

**💡 참고:** 새로운 카테고리를 만들었다면, 프롬프트 카드(PROMPT_CARDS)를 추가하거나 수정할 때 `category` 값으로 이 id를 똑같이 적어주셔야 해당 탭에 카드가 나타납니다.

**⚠️ 주의점 1:** 중괄호 블럭 안에는 `id`, `label`, `icon`의 3가지 항목이 **모두** 존재해야 합니다. 존재하지 않는다면 예기치 못한 오류가 발생할 수 있습니다. 각 항목은 쉼표로 구분되어야 합니다.

**⚠️ 주의점 2:** `id`의 값(Value)은 **생략할 수 없습니다.** 생략할 경우 오류가 발생할 수 있습니다. (`label`과 `icon`의 경우 생략이 가능하지만 추천하지 않습니다)

**⚠️ 주의점 3:** `id`가 'all'인 블럭(모두 보기)은 삭제해서는 안됩니다. 삭제하거나 수정할 경우 오류가 발생할 수 있습니다.

### 2.2. 프롬프트 카드 추가하기 (window.PROMPT_CARDS)

사용자가 실제로 클릭하고 선택하게 될 프롬프트 카드를 관리합니다.

* `id`: 해당 프롬프트 카드의 고유 영문 이름

* `category`: 이 카드가 속할 카테고리의 id

* `icon`, `title`, `description`: 화면에 보일 아이콘, 제목, 그리고 짧은 설명

* `template`: AI에게 실제로 보낼 질문 양식. 중괄호({})로 감싼 부분은 사용자가 선택할 수 있는 빈칸이 됩니다. (예: 가수 {artist}의...)

* `fields`, `key`, `label`, `options`: `template`에 만든 빈칸({artist}, {count} 등)에 들어갈 선택지들을 정의합니다. 자세한 내용은 2.2.1.에 설명되어 있습니다.

* `caution`: 하단에 띄울 주의사항 (생략 가능)

**💡 참고:** `caution`의 경우 생략이 가능합니다. 생략하려는 경우 `caution`을 남겨두지 않고 삭제하면 프롬프트 카드에서 주의사항을 표시하는 영역이 사라져 더욱 깔끔한 카드가 만들어집니다.

**⚠️ 주의점 1:** 중괄호 블럭 안에는 `id`부터 `fields`까지의 항목이 **모두** 존재해야 합니다. 존재하지 않는다면 예기치 못한 오류가 발생할 수 있습니다. 각 항목은 쉼표로 구분되어야 합니다.

**⚠️ 주의점 2:** `category`의 값이 window.PROMPT_CATEGORIES `id`와 일치하지 않으면 해당 프롬프트 카드가 제대로 표시되지 않거나 예기치 못한 오류가 발생할 수 있습니다.

#### 2.2.1. fields 블럭

`fields` 대괄호 블럭은 template에 만든 빈칸({artist}, {count} 등)에 들어갈 선택지들을 정의합니다.

각 선택지는 `fields` 대괄호 블럭 안에 중괄호 블럭({})을 만들어 관리합니다. 중괄호 블럭 안에는 `key`와 `label`, `options` 중괄호 블럭이 포함되어야 합니다.

* `key`: `template`에 만들어둔 빈칸({artist}, {count} 등) 중 하나와 같은 값을 가집니다. `key`와 `template`의 빈칸이 일치할 경우, 해당 위치에 선택지가 만들어집니다.

* `label`: 선택지 위에 표시될 질문('어떤 그림을 그릴까요?' 등)

* `options`: 해당 선택지의 선지들을 포함하는 중괄호 블럭

`options`는 다음과 같은 방식으로 선지들을 관리합니다.

```javascript
options: ['남진', '태진아', '송대관', '나훈아', '이미자', '주현미']
```

이 내용들을 종합하여, 아래의 예시와 같은 방식으로 `fields` 대괄호 블럭을 채웁니다.

```javascript
fields: [
      { key: 'age', label: '선물 받을 분의 연령대는?', options: ['20대', '30대', '40대', '50대 이상', '10대'] },
      { key: 'gender', label: '성별은 어떻게 되나요?', options: ['여성', '남성'] },
      { key: 'budget', label: '예산은 얼마인가요?', options: ['3만 원대 예산으로', '5만 원대 예산으로', '10만 원대 예산으로', '예산을 고려하지 않고'] }
    ]
```

**💡 참고:** 선택지가 필요 없는 프롬프트의 경우, `fields`를 비워 선택지가 없는 질문을 만들 수 있습니다. 아래 예시를 참고하십시오. **`fields`를 삭제하면 오류가 발생할 수 있습니다.**

```javascript
fields: []
```

**⚠️ 주의점:** `template`에 만들어둔 빈칸과 `key`의 값이 일치하지 않는 경우, 선택지가 제대로 작동하지 않거나 예기치 못한 오류가 발생할 수 있습니다.

### 2.3. 후속 질문 추가하기 (window.FOLLOWUP_PROMPTS)

AI의 답변을 받은 후, 이어서 질문할 수 있는 후속 질문을 관리합니다.

따옴표('') 안에 원하시는 질문을 적고 쉼표(,)로 구분해서 이어 붙여주시면 됩니다.

## 3. 변경 사항 저장 및 반영하기 (GitHub에 올리기)

데이터를 수정한 후에는 본인의 GitHub 저장소에 변경 사항을 반영(Commit)해야 웹사이트에 업데이트됩니다. 편하신 방법을 선택하여 진행해 주세요.

### 3.1. GitHub 웹사이트에서 직접 수정하기 (초보자 추천)

프로그램 설치 없이 웹 브라우저에서 바로 파일을 수정하고 저장하는 가장 쉬운 방법입니다.

1. 본인 계정으로 포크(Fork)한 GitHub 저장소에 접속합니다.
2. `js` 폴더를 클릭한 후, `prompts.js` 파일을 클릭합니다.
3. 우측 상단의 **연필 모양 아이콘(Edit this file)**을 클릭하여 편집 모드로 들어갑니다.
4. 웹 브라우저 상에서 코드를 직접 수정하거나 추가합니다.
5. 수정이 끝났다면 우측 상단의 **[Commit changes...]** 초록색 버튼을 클릭합니다.
6. 어떤 내용을 수정했는지 간단한 메모(예: "음악 카테고리 프롬프트 추가")를 적고 다시 **[Commit changes]** 버튼을 누르면 즉시 반영됩니다.

### 3.2. 터미널(Git)을 사용하여 수정하기 (개발자용)

로컬 PC에서 파일을 수정한 뒤 Git 명령어를 통해 GitHub로 업로드하는 방법입니다.

이미 `git clone`을 통해 로컬로 가져온 상태라면 아래 순서대로 명령어를 입력하여 변경 사항을 저장하고 업로드(`push`) 합니다. 

```bash
# 0. 파일이 위치한 폴더로 이동합니다.
# [주소]로 표기된 부분에 작업 중인 위치를 입력합니다.
# ex) cd C:\Users\user\Documents\ai-playground
cd [주소]

# 1. 변경된 파일들을 모두 스테이징 영역에 추가합니다.
git add .

# 2. 어떤 변경을 했는지 메시지와 함께 기록(Commit)합니다.
git commit -m "새로운 프롬프트 추가 및 카테고리 수정"

# 3. 변경된 내역을 GitHub 저장소로 업로드(Push)합니다.
git push origin main
```

만약 `git clone` 명령어를 사용하여 파일을 받은 것이 아닌 경우, 작업한 로컬 폴더에서 Git 저장소를 초기화한 후 원격 저장소 주소를 연결하는 과정이 선행되어야 합니다. 위의 명령어들을 실행하기 전 아래 명령어들을 실행하십시오.

```bash
# 0. 파일이 위치한 폴더로 이동합니다.
# [주소]로 표기된 부분에 작업 중인 위치를 입력합니다.
# ex) cd C:\Users\user\Documents\ai-playground
cd [주소]

# 1. Git 저장소 초기화
git init

# 2. 원격 저장소 연결
# [주소]로 표기된 부분에 포크한 저장소의 주소를 입력합니다.
# ex) git remote add origin "https://github.com/MontyCPlusPlus/ai-playground/"
git remote add origin [주소]
```

## ⚠️ 주의사항 (오류가 발생했을 때)

데이터를 추가하다가 웹페이지가 하얗게 변하거나, 프롬프트가 표시되지 않거나, 웹페이지가 작동하지 않는다면 아래 사항들을 확인하십시오.

* 쉼표(,) 확인: 객체({ })와 객체 사이, 배열([ ]) 안의 항목과 항목 사이에는 반드시 쉼표가 있어야 합니다. (마지막 항목 뒤에는 없어도 됩니다.)

* 따옴표(' ') 짝 맞추기: 텍스트를 입력할 때 시작과 끝의 홑따옴표 짝이 맞는지 확인하십시오.

* 오타 및 대소문자 주의: 속성명(category, title, options 등)의 스펠링이 틀리지 않았는지 확인하십시오.

* key 일치: template 안의 {단어}와 fields 안의 key 값이 일치하는지 확인하십시오.

# 프롬프트 데이터 수정 가이드 (`js/prompts.js`)

이 문서는 AI Playground 웹사이트에 새로운 프롬프트를 추가하거나 기존 내용을 수정하는 방법을 안내합니다. 

이 프로젝트는 별도의 데이터베이스(DB) 없이 순수 웹 브라우저 환경에서 동작하므로, `js/prompts.js` 파일 내부의 데이터만 수정하면 웹페이지에 즉시 반영됩니다.

## 1. `prompts.js` 데이터 구조

프롬프트 데이터는 자바스크립트 객체 배열(Array of Objects) 형태로 저장되어 있습니다. 파일을 열어보시면 아래와 비슷한 구조를 확인할 수 있습니다.

```javascript
const prompts = [
  {
    category: "건강/의료",
    title: "약 복용 시간 잊었을 때 질문하기",
    text: "제가 아침 8시에 먹어야 하는 혈압약을 깜빡하고 지금 생각났는데, 지금 먹어도 될까요?"
  },
  {
    category: "일상/취미",
    title: "트로트 노래 추천받기",
    text: "신나는 7080 트로트 노래를 5곡만 추천해주고, 누구 노래인지도 알려줘."
  }
  // 새로운 프롬프트는 이 아래에 계속 추가할 수 있습니다.
];
